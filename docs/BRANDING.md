# Intent visual identity

The project has an author-supplied square logo: a cyan-to-violet stylized `i` and forward-arrow monogram over a dark background, with the word **Intent** in white underneath.

## Intended placements

- Repository `README.md` hero, using a relative image path once the original image is committed.
- Documentation and project landing page.
- GitHub Release announcements and project social cards.
- PyPI project description (use an absolute publicly hosted image URL there).

## Asset preparation

Store the original author-supplied image under `assets/branding/intent-logo.jpg` and a 512 × 512 variant under `assets/branding/intent-logo-512.png`. Preserve the artwork; do not recreate or replace it with a different icon. The logo belongs to the Intent language, **not automatically to apps compiled with Intent**.

## Repository status

The original binary artwork must be uploaded separately. Do not add a broken README image reference until the image is committed. The canonical file is the author-supplied image, not a generated approximation.
