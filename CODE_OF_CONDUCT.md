# Code of Conduct / Правила сообщества

## Русский

Мы приветствуем уважительное, профессиональное обсуждение независимо от уровня опыта и происхождения участника. Критика технических решений допустима; личные оскорбления, угрозы, травля, дискриминация, публикация личных данных и спам недопустимы.

При конфликте сообщите сопровождающим проекта через GitHub issue, если это безопасно и не раскрывает личных данных. Для чувствительных обращений используйте приватный канал связи с владельцем репозитория, если он опубликован в профиле GitHub. Не размещайте конфиденциальные сведения в публичных issue.

Сопровождающие могут скрывать или удалять нарушения и ограничивать участие для защиты сообщества.

## English

Be respectful and professional regardless of experience or background. Technical criticism is welcome; personal attacks, threats, harassment, discrimination, doxxing and spam are not.

Report public issues through GitHub when appropriate. For sensitive reports, use a private contact channel published by the repository owner, if available; do not disclose personal information in public issues.

Maintainers may moderate content and restrict participation to protect the community.
