# Sedrava 0.7 lineage — release notes / История выпуска

**Current status:** Sedrava has **not** been published to PyPI. The current repository source version is `0.7.0a1`; this is not a claim that a Sedrava release exists. Proposed next pre-release version: `0.7.1a1`, subject to verification and approval.

The project evolved from an earlier experimental language. That project's distribution and release history remain unchanged and can be reviewed through Git history and existing GitHub releases. This rebrand introduces a new distribution name (`sedrava`), CLI (`sedrava`) and source extension (`.sdr`) without compatibility aliases.

**Статус:** пакет Sedrava ещё не опубликован в PyPI. В исходном коде сохранена версия `0.7.0a1`, но она не означает наличие выпуска Sedrava. Предлагаемый следующий предварительный выпуск — `0.7.1a1` после проверки и отдельного согласования.

Существующие исторические релизы и Git-коммиты сохраняются. Ребрендинг меняет имя дистрибутива, CLI и расширение исходных файлов, не изменяя синтаксис и семантику языка.

See [release checklist](RELEASE_0_7.md) and [rebrand instructions](REBRAND.md).
